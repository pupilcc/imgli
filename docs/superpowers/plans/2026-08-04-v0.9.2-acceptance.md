# v0.9.2 验收用例

Theme: **instant reuse · site name surface · stats honesty**  
Scope: patch on v0.9.1. No full white-label.

## A. 同用户秒传复用（P0）

| ID | 场景 | 前置 | 操作 | 期望 |
|----|------|------|------|------|
| A1 | 同用户同选项复传 | 登录用户已上传公开图（无过期/无限次/无口令/无相册） | 再传相同字节、相同选项 | `instant=true`，`reused=true`，**同一 `key`**；图库仍 **1** 条；`used_storage` **不二次累加**；`files.ref_count` 不变 |
| A2 | 同用户不同相册 | 已有无相册 live 图 | 同字节指定相册上传 | `instant=true`，`reused=false`，**新 key**；图库 2 条；配额 +1 份；`ref_count+1` |
| A3 | 同用户不同可见性 | 已有 public | 同字节 private | 不共享 File（跨 surface）；新对象；不复用 key |
| A4 | 同用户不同有效期/次数/口令 | 已有永久图 | 同字节带 expires / max_views / password | 新 key（选项不一致） |
| A5 | 跨用户秒传 | 用户 A 已传 public | 用户 B 传相同 public 字节 | B 得 **自己的新 key**；`instant=true`，`reused=false`；共享 File；`ref_count+1`；B 配额扣费；**不**返回 A 的 key |
| A6 | 游客撞库 | 登录用户已传 | 游客同字节 | 新 guest image；`UserID=null`；共享 File；不扣登录用户配额；不 `reused` |
| A7 | 软删后重传 | 用户将唯一 live 图软删 | 同字节再传 | **不**复用 trash 行；新建 live image（或显式 restore 策略外，0.9.2 选新建） |
| A8 | 审核继承 | File 上已有 rejected sibling | 跨用户秒传 | 新 image status 继承 rejected/pending |
| A9 | 文案 | A1 / A2 前端 | 看上传卡片 | A1：已有图返回原链；A2：内容秒传、已建新外链 |

### API 契约

```json
{
  "key": "…",
  "instant": true,
  "reused": true,
  "name": "…",
  "size": 123,
  "links": { }
}
```

- `reused` 仅当返回既有 live image 时为 `true`；新建（含跨用户秒传）为 `false` 或省略。
- 客户端可忽略 `reused`；`instant` 语义保持「未重新落盘原图」。

## B. 站点名称触达（P0 / L0）

| ID | 场景 | 期望 |
|----|------|------|
| B1 | 管理端改 `site_name` 为非默认 | 保存成功；`GET /config` 立即反映（invalidate） |
| B2 | 浏览器标题 | `document.title` 以站名为主（默认 img.li 时仍带产品中文） |
| B3 | 登录用户顶栏 | BrandLockup **字标**显示站名；**鲤鱼 mark 保留** |
| B4 | 游客壳 / 广场壳 / 登录壳 | 同上（站名可见） |
| B5 | 管理后台壳 | 显示站名 + `ADMIN` 徽章（或产品锁标 + ADMIN，二选一以实现为准；须可见站名或保留产品锁标且设置有说明） |
| B6 | 页脚 / 邮件 / OG | 仍用站名（回归不破坏） |
| B7 | 默认 `img.li` | 顶栏仍为产品锁标 `img.li`（带点样式） |
| B8 | 设置 hint | 「站点名称」旁说明影响面：标题、顶栏字标、页脚、邮件、分享等；**不**替换鱼标图形 / 非全白标 |
| B9 | `oss_credit` / 开源署名 | 页脚仍可展示「基于 imgli」；关 credit 不移除 mark |

## C. 存储策略统计诚实度（P1）

| ID | 场景 | 期望 |
|----|------|------|
| C1 | 列表展示 | 每策略可见 **对象数**（`file_count`）与 **占用字节**（`used_bytes`） |
| C2 | live / trash 拆分 | API 含 `live_image_count`、`trash_image_count`；UI 可读 |
| C3 | 软删后 | live 图进回收站 → `live_image_count-1`，`trash_image_count+1`；`file_count`/`used_bytes` **不变**（对象仍占盘） |
| C4 | 彻底删除且无共享 | purge 后 `file_count`/`used_bytes` 下降 |
| C5 | 文案 | 说明「对象数含回收站仍占用的物理文件；彻底删除后下降」 |
| C6 | （可选）深链 | 从策略可跳到 `/admin/images?policy={id}` |
