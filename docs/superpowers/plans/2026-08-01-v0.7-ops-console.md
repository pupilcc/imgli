# v0.7.0 Ops Console · Health · Deploy — Implementation Plan

> **For agentic workers:** implement task-by-task; checkbox syntax for tracking.

**Goal:** Admin-visible self-host diagnostics (doctor + runtime summary + reverse-proxy mismatch), Ops IA (system page with upgrade/cleanup/migrate/backup), first-run checklist, upgrade preflight — ship as **v0.7.0**.

**Architecture:** Reuse `internal/doctor` for checks; add admin-only `GET /api/v1/admin/system/health` combining doctor report + read-only runtime fields from `config.Config` and the current request. SPA `/admin/system` page owns Health + Upgrade + Cleanup; browser origin vs `base_url` is client-side compare. No dual-write of env-level knobs.

**Tech Stack:** Go (chi, existing handler patterns), React admin SPA, vitest/go test, i18n zh/en.

**Milestone:** https://github.com/yixian-huang/imgli/milestone/6 · Issues #74–#79

## Global Constraints

- Admin-only endpoints (`RequireAdmin`); never expose secrets (SMTP keys, S3 keys, full private paths if sensitive — data_dir OK for admin).
- Do **not** make `listen` / DB DSN / `trust_proxy` editable from UI.
- Docker: keep binary upgrade blocked; improve messaging only.
- AGPL trunk; bilingual admin strings.

## Suggested API shape

```json
{
  "doctor": {
    "hard_fail": false,
    "checks": [
      { "name": "base_url", "level": "warn", "message": "..." }
    ]
  },
  "runtime": {
    "version": "dev",
    "base_url": "http://localhost:8686",
    "trust_proxy": false,
    "listen": ":8686",
    "data_dir": "/data",
    "install": "binary",
    "request_host": "img.example.com",
    "forwarded_proto": "https",
    "forwarded_for_set": true
  }
}
```

`install`: `docker` if `version.IsDockerish()`, else `binary`.
